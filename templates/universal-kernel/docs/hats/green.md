# Green hat — provocation and alternatives

> **KERNEL DOC — project-agnostic, inherited verbatim.** Role, firing rules, the
> valve, and the Kaizen contract are kernel. Tool paths are overlay data.

Greppable summary: the creative-divergence hat. Already dedicated as a
TOOL: the po battery (`tools/po_battery.py`, skill
`docs/skills/po_provocation.md`) is de Bono's own Green-hat engine, made
mechanical. This file adds nothing to how po works — it locates po in the
registry and states the Green hat's registry obligations (memory, Kaizen,
valve) once.

## Role

Run the full operator battery on the target statement (all operators,
standalone + random combos), write every provocation down before judging
any, extract value by MOVEMENT (≥2 techniques per provocation), harvest
candidates traceable to their provocations. Provocations are stimuli,
never facts. Full spec: `docs/skills/po_provocation.md` — that document
remains the single source of truth for firing rules and operators.

## Exists today

`tools/po_battery.py` (seedable generator, guarantees no operator is
forgotten); the skill doc; M6 in the Kaizen ledger.

## Model binding

Cheap/`mechanical` tier — divergence is volume work, and judging quality
happens later at the convergent gates, not here.

## Fires when

Per the skill doc: divergent moments only (Friction pre-work opening move,
sprint/architecture planning, design directions, generative-candidate
ideation) — never inside convergent gates, never into memory or trust
surfaces. In a dedicated-parallel hat run, Green fires AFTER White's facts and
BEFORE the Yellow/Black argument, so the experts evaluate a widened option set
instead of only the first idea (the structural blindness of any expert panel:
it can only judge the one option handed to it).

## Owned memory & assets

The M6 harvest table in `docs/metrics/KAIZEN_LEDGER.md` (provocations run,
ideas surviving gates, dead ends logged); harvest appendices in the
strategy docs its runs produced.

## Kaizen

- **Measure (M6, existing):** po-sourced ideas surviving the normal gates.
- **Counter-measure:** dead ends are LOGGED, not hidden (a battery
  reporting only winners is curating, not diverging) — and batteries fired
  on trivial tasks are a cost-discipline defect (ritual is not insight).
- **Escape definition:** a divergent moment where the battery was mandatory
  and skipped, or a harvest generated and never moved-from (M2, class:
  ritual-without-harvest).

## Must never

Enter memory, candidate data, or user-facing copy except through the
normal gates; run inside a convergent verdict; be "answered" instead of
moved-from.

## Retirement condition

None foreseeable — divergence cannot be mechanized into a checklist without
ceasing to be divergence. The battery GENERATOR is already mechanical; the
movement half stays judgment. Archive only if the founder retires po itself.
