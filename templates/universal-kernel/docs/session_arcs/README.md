# docs/session_arcs — chronological session records

**KERNEL text.** One file per meaningful session:
`YYYY-MM-DD_short-slug.md`. STATE.md is the always-current rollup; arcs
explain HOW the state got there — the decisions, the findings, the dead
ends, the review rounds and what they caught.

Write the arc at session close, before updating STATE. An arc is narrative
and may be long; STATE must stay short and current. When they disagree,
STATE is authoritative for "now" and the arc is authoritative for "why".

Record what actually happened, including what failed. An arc that reads as
uninterrupted success is either a trivial session or a dishonest one.
