# Everything needed to run `bash tools/validate` from a fresh clone.

# WHY THIS FILE EXISTS (v1 done-criterion 3, BAR G5, R-058): the gate used to turn
# four rows red in a default environment for reasons that were not code — three from
# interpreter packages nobody had written down, one from a shallow clone. Presented in
# the same red column as a real regression, they train everyone to scan past red.
# `tools/env_preflight.py` now names those two causes explicitly, and this file makes
# them go away.
#
# Install with the one command in `tools/bootstrap_dev.sh`, which also un-shallows the
# clone (the arming-evidence binding cannot be proven without full history — R-036).
#
# DELIBERATELY UNPINNED, unlike worker/requirements.txt. Those pins are bound into the
# golden exam's harness-manifest hash, so bumping one is a reviewed harness change.
# Nothing here touches the exam: these are test-execution tools, and pinning them
# would add upgrade friction that buys no evidence.
