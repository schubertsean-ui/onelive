   - Expected: 100% of the counted union on https://1live.co (same title + when + place = one).

2. **Fixer** — changes only what the Definer named.

3. **Publisher** — puts the fix on master (when authorized), runs ingest if the hole is catalog, opens https://1live.co, counts.

   - Fail = count did not reach 100%. New Definer. Do not start a second theory.
