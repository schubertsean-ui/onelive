### (b) Implications for a press-release/disclosure aggregation + diff-analysis product

- **Agent-reachability is becoming table stakes, not differentiation.** Between Jul 2025 and May 2026 essentially every major financial-data incumbent (FactSet, S&P/Kensho, LSEG, Moody's, Morningstar, Daloopa, Fiscal.ai, Massive, Alpha Vantage, Benzinga, FMP) shipped an official MCP surface; commentary now frames "be callable inside Claude/ChatGPT" as a survival requirement. A disclosure-diff product should ship a remote OAuth MCP server from day one (favoring stateless-friendly transport per current spec direction — the specific release-candidate citation was struck as time-incoherent, see row 6) — the differentiator is the *diff/verified-change* payload, not the pipe.
- **The unit of value is shifting from raw data to pre-verified, source-linked deltas.** Daloopa's moat framing (every datapoint hyperlinked to the source filing) and Anthropic's connector roster show agents reward provenance-rich, citation-native data. A diff-analysis product's "what changed vs. the prior release, with sourced evidence" is precisely the artifact LLM agents can't cheaply reconstruct — expose diffs as first-class MCP tools/resources, not pages.
- **"Skills" layered on top of MCP is the emerging pattern.** Fiscal.ai's Fiscal Skills, S&P's agent-skills plugin, and Moody's purpose-built agents show vendors packaging *analyst workflows* (not just endpoints). Ship named skills like "compare_guidance_language(qtr_over_qtr)" or "flag_new_risk_factors" — that's what earned S&P/Moody's placement inside Claude for Financial Services.
- **Distribution is consolidating into three agent storefronts:** Anthropic's Claude for Financial Services connector list, Databricks MCP Marketplace (LSEG, FactSet, Nasdaq, Moody's, D&B), and cloud-native channels (S&P+AWS Quick Suite, LSEG+Microsoft). A small vendor's fastest path to enterprise buyers is getting listed in one of these, since Fiscal.ai and Daloopa (both startups) already made Anthropic's partner roster.
- **Enterprise deployment constraint = governance, not capability.** Stacklok's FS survey says security is the top blocker and SaaS-only MCP hosting is a "non-starter"; FactSet leads with audit logging and access control. Plan for VPC/self-host or per-tenant OAuth with full audit trails as an enterprise requirement, and note the Nov-2025 spec (mandatory PKCE, CIMD) as the compliance baseline.
- **Discontinuity risk: the model vendors are moving up-stack.** Anthropic's 10 finance agent templates and Excel add-ins, plus OpenAI's bank alliances (BBVA 100k+ seats, Morgan Stanley, BNY), mean generic "summarize the press release" workflows get commoditized inside the assistant itself within 1-2 years. Defensible ground is the corpus + the diff engine + golden-set accuracy guarantees the assistant must call out to — with Bloomberg's continued MCP absence showing that walled-garden strategies leave a gap challengers can occupy.
