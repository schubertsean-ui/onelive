# Proof

Proof is one printed line on the live site.

## Measure

1. Open https://1live.co
2. Open https://1live.co/tonight
3. Copy: `Showing N of M …`
4. That is the result.

Right now: Showing 16 of 16 Today.

## Pass / fail

| Work | Pass |
|---|---|
| Catalog / ingest / promote | N on that page moved toward that locale’s union |
| Ticket B | N ≥ counted union (test floor: Chronicle today 196) |
| View-only change | Same rows still exist; filter did not delete |

Fail: N unchanged after a catalog change. Say `still 16`.

## Not proof

- A commit on master
- A green desk-ingest job
- A pull request
- An FL file
- This chat

Master is where code lives. It is not the measure.

## Who may say Success

Only step 11 of the Fix Process, using this line.
Nobody else.

## After every product change

Merge to master → ingest write=true only if a product file changed → open the two URLs → write N.
If ingest is already walking, do not start another.
