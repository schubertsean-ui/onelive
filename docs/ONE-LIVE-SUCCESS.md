# 1Live Success catalog

Aligned to ONE-LIVE-VISION.md and the Goals in docs/1Live_Platform_Plan.md.
M (Monitor) probes these. A miss starts Fix Loop step 1.
Process stays failure-type agnostic. These are the Success pictures, not extra steps.

Universal. Any locale. Austin is the test pack.

## Vision → Success

| Vision line | Success looks like | Probe |
|---|---|---|
| Map, not shop | Happenings are listed because they are on, not because someone paid | No pay-to-rank control. No sponsored slot on the default view |
| Every category, any locale | Any kind, any city the person searched or the device is in, can appear | Pack exists or can be added; no category dropped; Other is residual |
| No category weighting | Music is not the product. Kinds sit as equals | Default view is not a music-only rail |
| Publishers trusted until wrong | One trusted door + title is enough to exist | No second-desk hold; disputed is shown |
| On-device plans | What a person saves lives on their device | No server-side attendance log |
| Heartbeat is de-identified pulse | City pulse, not a person | No named-person trace |
| Beautiful + automagical | In and out. The map works without a manual |
 Page loads; listings appear without an operator click |
| Trust serves the vision | Gates protect the map; they are not the product | A missing end does not hide a real happening |

## Goals → Success

| Goal | Success looks like | Probe |
|---|---|---|
| 1. Answer tonight in under 10 seconds | Today / Tonight for that locale answers on the first screen | 1live.co and /tonight load and show that locale’s window |
| 2. Every real activity findable. Discovery never for sale | 100% of that locale’s counted aggregator union is on 1Live. No paid boost | Live unique N vs union U; no sponsored discovery |
| 3. Time given back | Anti-attention: in and out | Default view is scannable; no engagement trap |
| 4. Listed by default if it is on | Existence = trusted door + title. Views filter; they do not delete | Catalog holds the row; Today is a filter |
| 5. Places appear from activity, not payment | Place comes from the happening | Place row exists because a desk printed a place |
| 6. Social validates, never defines | A social post is not enough alone to mint a happening | Trust classes honored |
| 7. No sponsored discovery | Rank is not for sale | No pay-to-rank |
| 8. Heartbeat is city pulse, not a person | Aggregate only | No individual trail |

## How M uses this

For each Vision line and each Goal: run the probe.
If the probe is not Success, M writes: which Vision/Goal, actual vs Success, then kicks Find Failure.
M does not patch.
