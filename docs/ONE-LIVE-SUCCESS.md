1. World statement still true on the live system: easy to find, fairly represented, culturally valued, soul intact.
2. What it is: system of record for a happening — any category, any locale, person, organization, group, activity, artist, performance, place-first.
3. Publish line: 1Live accurately publishes every activity anywhere in the world.
4. Goals 1–8: each PASS / FAIL / UNVERIFIED.
5. Lock lines: map not shop; no refused category or locale; no invented fields; no pay-to-rank.

Write only the rows that FAIL. Then start Find Failure.
