# 1LIVE — Engagement Canon: Invariants vs. Testable Hypotheses v1

**Status: FOUNDER-RATIFIED 2026-08-01** ("Adopt invariants-vs-testable-
hypotheses split is excellent" — decision record
`docs/memory/decisions/2026-08-01_truth-states-v2-and-hypothesis-split.md`).
Adopted from the external review §5.6. The design brief v2.4 remains
ratified canon; this doc is the founder-instructed recasting of its
engagement *effectiveness* claims as defaults-to-test. Trust-display rules
are untouched — they were never hypotheses.

## 1 · Invariants (never A/B tested, never relaxed)

1. Facts come from the verified event record only — content never invents.
2. One primary action per piece.
3. No fabricated urgency (no fake scarcity, no invented deadlines).
4. No unverified price or availability (the Continental correction, C-12).
5. Accessible with sound off; captions and readable first frames (WCAG
   2.2 AA per the brief).
6. Owner-approved rights only — nothing generated touches the artist's
   art; footage/audio used only with documented permission (the artist
   rule, brief §6).
7. No send and no budget without explicit approval (risk-tier boundaries
   pending the founder's standing-authorization decision — until then,
   everything outbound requires the tap).
8. Trust-display rules of the brief (no badges/"confirmed" text;
   quiet-icon pattern) — ratified canon, out of scope for testing.

## 2 · Testable hypotheses (defaults until data says otherwise)

Each row is a default we ship with, an explicit hypothesis, and a
measurement note. Outcome classes per
`ONE_LIVE_TRUTH_STATES_v2.md` §4; results enter the claim ledger with
badges, never as bare assertions.

| id | default we ship | hypothesis to test | measurement note |
|---|---|---|---|
| H-E1 | video first | video outperforms still for event discovery posts | matched-event comparison; attendance-class outcomes, not views |
| H-E2 | live/owned audio | live audio beats licensed track for venue authenticity | rotate across recurring nights |
| H-E3 | emotional opening | emotion-led opening beats information-led | alternating weeks on recurring events |
| H-E4 | 6–9 p.m. send window | evening window beats morning/midday for local event content | staggered rollout across venues |
| H-E5 | five-card carousel | 5 cards beat 3 or 8 (attention vs. completeness) | carousel completion + saves + door-class outcomes |
| H-E6 | hook structure (attention → emotion → fact → curiosity → action) | this sequence beats simpler structures | per-card drop-off analysis |
| H-E7 | carousel over flyer | the "3-to-1" line — HYPOTHESIS until a controlled comparison exists (ledger C-11) | identical denominator, defined metric, stated confounders |
| H-E8 | offer framing | specific-perk framing beats percentage-discount framing | directly-tracked redemptions only |
| H-E9 | CTA wording | concrete verb + time beats generic "learn more" | tagged-link attribution, labeled Attributed |
| H-E10 | audience radius | tight geo-radius beats broad for door outcomes | holdout where volume allows |

**Low-volume rule (verbatim intent from the review):** rotate variants
across recurring events rather than pretending one small event provides
statistically decisive A/B results. Uncertainty intervals accompany every
readout.

## 3 · Custody

- A hypothesis result never edits an invariant. If a test result appears
  to argue an invariant down, that is a founder-crucial escalation, not a
  finding.
- Graduating a hypothesis to a stated claim requires: ledger row, outcome
  class INCREMENTAL or Directly tracked, and population/scope preserved in
  the approved wording.
- The Descriptor Foundry and po battery remain the divergent-side tools;
  this library is the convergent side — stimuli in, evidence out.
