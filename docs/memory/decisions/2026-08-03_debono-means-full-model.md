## The rule

When the founder invokes de Bono / po / the battery by name, the deliverable
contains the ENTIRE model, written out:

1. **Every operator** (P1 escape · P2 reversal/invert/opposite, both
   directions · P3 exaggeration up AND down · P4 distortion · P5 wishful ·
   P6 absurd · P7 random entry · P8.1–P8.6 random+each), each with its
   provocations WRITTEN in the deliverable — never "was run" as a claim with
   the writing omitted. Step 0 assumptions listed first.
2. **Movement per provocation** (≥2 techniques), written.
3. **Harvest table**, every idea traceable to its provocation ID.
4. **All the hats** (docs/hats/): Blue frame pre-registered → White facts →
   Green (the battery) → Yellow and Black passes → devil's-advocate against
   any consensus → Blue merge that PRESERVES conflict. Red = founder, never
   an agent. Sequential mode is acceptable for analysis-level decisions;
   dedicated-parallel for irreversible/founder-crucial ones (registry rule
   unchanged). A generator-side Black pass carries no adversarial authority —
   say so in the document; the real Black seat is the non-Claude review.
5. **Condensing is a defect class** (Kaizen marker
   `condensed-thinking-run`): claiming completeness while delivering a
   digest is the false-confidence-gate shape applied to thinking tools.
   Long ≠ complete either: complete means every operator's provocations and
   movement are on the page.
