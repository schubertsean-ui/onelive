# Valid Source Library

Rule (founder 2026-09-09):

- A **validated** source publishes on **one** door.
- Two sources are only for an **unvalidated** mention (one unofficial social post, an invalidated statement).
- Do not re-decide Chronicle, Do512, Ticketmaster, Bandsintown, Meetup, or any other validated door on every row.

This is not a second database. The library is:

1. `sources/locale_packs/` — doors for a locale
2. `sources/master_sources_catalog_120.json` — named sources
3. `sources/valid_sources.json` — validated vs unvalidated
4. The `source` row in the live DB — flag `validated` once, reuse forever

Validated examples (not an Austin-only list): established local desk, ticketing, official venue/artist/presenter calendar, civic calendar, Meetup-class marketplace the pack named.

Unvalidated: one unofficial social post. That stays a lead until a validated door or a second independent source exists.

Gate: if the door is validated → promote. If the only evidence is unvalidated → do not promote on 1.
