# 1Live when

1Live is the one. Every door maps into: title / when / place / kind / via.

## When is two facts

| Slot | Meaning | Required? |
|---|---|---|
| start date | Calendar day the door printed | Enough to date the happening |
| start time | Clock the door printed | Optional |
| end date / end time | Only if the door printed an end | Optional |

Do not invent a minute. A date-only row stays a date.

## Timezone

Timezone is on the locale pack (`timezone` IANA name).  
CAPCOG test pack is `America/Chicago`. That is not 1Live’s world zone.  
Today = that locale’s calendar day.

## Year

Year is current unless that page or site printed a 20xx. Year is not a gate.

## Views

Today / Tonight / All upcoming are filters on rows that already exist.
A filter does not decide catalog membership.
