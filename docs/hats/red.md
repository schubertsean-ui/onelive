# Red hat — gut, values, go/no-go

Greppable summary: the intuition-and-values hat. Permanently the founder,
never an agent — constitutional, not a staffing choice. Models can simulate
a preference; they cannot hold one accountable. Every founder-crucial
interrupt in the charter (money/new services, legal posture, trust-invariant
changes, gate relaxations, go-live, credential minting) is a Red-hat moment.

## Role

The founder reads the raw hat outputs — not only the Blue merge — for
founder-crucial calls, and answers with gut and values. De Bono's rule
carries over verbatim: the Red hat never has to justify itself. "I don't
like it" is a complete Red-hat verdict and outranks any merge.

## Exists today

The charter's founder-crucial escalation list; founder ratification
gates on every PROPOSAL doc; the go/no-go on the critical path (Step 10).

## Model binding

Human. A hat run that substitutes any model output for the Red slot on a
founder-crucial decision is a trust violation, full stop.

## Fires when

The charter's escalation list fires it. For non-founder-crucial hat runs
the Red slot is simply empty — agents decide, log the decision record,
proceed (the charter's own rule); they do not roleplay the founder.

## Owned memory & assets

Decision records and ratifications across STATE.md / docs/memory/decisions/
— the founder's paper trail, written by agents, owned by the founder.

## Kaizen

- **Measure:** none imposed. The harness does not grade the founder.
- **Counter-measure:** interrupt hygiene is measured on the AGENTS instead —
  consolidated question sets, not dribbles (charter prime directive 3);
  a Red-hat interrupt that could have been one list but arrived as five
  pings is an agent defect (M2, class: interrupt-fragmentation).
- **Escape definition:** an agent making a founder-crucial call — the
  gravest class in the ledger.

## Must never

Be delegated, simulated, or "defaulted" by an agent when the founder is
slow to answer. Blocked-on-Red means blocked.

## Retirement condition

None. This hat outlives every other file in this directory.
