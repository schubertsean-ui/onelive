# FL-008

Failure: a card shows the wrong hour (6 p.m. printed, 1:00 PM on 1Live).
Why: a printed clock was stored with no timezone. Postgres and the card treated it as UTC.
Success: a printed clock is that locale pack’s clock. Austin pack = America/Chicago. The next locale pack uses that pack’s zone. Never naive. Never UTC unless the page printed Z.

Apply in worker/locale_pack/house_dates.py `_iso`.
- Stamp `ZoneInfo` from the pack timezone.
- `Thu., Sept. 10, 6 p.m.` → `2026-09-10T18:00:00-05:00` in the Austin pack.
- Same rule on every desk, every locale.

Do not invent a minute. Date-only stays date-only (FL-003).
